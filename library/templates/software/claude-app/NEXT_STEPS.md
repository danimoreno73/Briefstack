# Next steps: {{name}}

This folder is ready to become a project in the Claude desktop app. The
project itself has to be created by hand; these are the exact steps.

## 1. Create the project from this folder

1. Open the Claude desktop app.
2. Create a new project and choose to use an existing folder on your computer.
3. Select this folder and name the project "{{name}}".

A project created from a folder stays on this computer; it is not saved to
your Claude account.

## 2. Paste the instructions

Open [INSTRUCTIONS.md](INSTRUCTIONS.md), copy all of it, and paste it as the
project instructions.

## 3. Create the scheduled tasks

Scheduled tasks need a paid plan. Create each task listed below from the
project, or from Scheduled → New task in the sidebar, using its schedule and
pasting its text as the prompt. If no task is listed, this project has none:
skip this step.

{{scheduledTasks}}

## 4. Start working

Open the project and start a conversation. A good first message: "Read
docs/BRIEF.md and propose the first step."

## If you only use Claude on the web

1. On claude.ai, create a new project named "{{name}}".
2. Paste the contents of [INSTRUCTIONS.md](INSTRUCTIONS.md) as the project
   instructions.
3. Upload the files from this folder to the project, starting with
   [docs/BRIEF.md](docs/BRIEF.md). Skip the `.git` and `.briefstack` folders.
   A web project keeps its own copies, so upload a file again when it changes.
