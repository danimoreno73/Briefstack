# Progress

What happened, session by session, and a regular review against
[the brief](BRIEF.md). Newest entries first; keep each one short.

## Review checklist

Use it at the end of each week, or at each milestone:

1. Which "Done when" item moved forward? Which did not, and why?
2. What took longer than expected? What was easier?
3. Does the plan still fit the time and energy available? If not, cut scope.
4. What is the single next step?
5. Update "Current status" in the brief.
